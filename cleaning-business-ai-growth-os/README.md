## Rebuilding
All deliverables are generated by the scripts in `../cleaning-business-ai-growth-os-build/` (Python 3 with openpyxl, python-docx, python-pptx and reportlab, plus LibreOffice for the PDF conversions and test recalculation):
```
cd cleaning-business-ai-growth-os-build
python3 build_workbook.py ../cleaning-business-ai-growth-os
python3 build_guides.py   ../cleaning-business-ai-growth-os
python3 build_forms.py    ../cleaning-business-ai-growth-os/CLIENT-FORMS/editable-docx
python3 build_marketing.py ../cleaning-business-ai-growth-os/MARKETING-KIT
python3 qa.py ../cleaning-business-ai-growth-os /tmp/qa      # 53 automated tests
```
